# 🧠 Super Aap - AI-Driven Learning & Entertainment Platform

**Super Aap** is a full-stack, AI-integrated platform that unifies educational tools, secure online examinations, and entertainment services. Built with a modular approach, it ensures seamless navigation, secure user experience, and smart content delivery using AI/ML.

---

## 🚀 Features

### 🎓 **MyProctor Module – AI Proctored Examination System**

* **Face Recognition & Verification**
* **Real-Time Monitoring** (gaze detection, face tracking)
* **YOLOv5-based Object Detection** to flag unauthorized devices or persons
* **Activity Logging** with MongoDB
* **OTP and Camera Verification** for secure login

### 📊 **Academics Module**

* Exam portal with result tracking
* Course recommender system using user history and ML
* Dashboard for performance analytics and upcoming exams

### 🍿 **Entertainment Module**

* Show/movie seat booking with timer and concurrency handling
* Razorpay-integrated payment gateway
* ML-based recommendation system for personalized content

---

## 🛠️ Tech Stack

* **Frontend**: HTML, CSS, JavaScript, Bootstrap, React (in progress)
* **Backend**: Flask (Python), Node.js, Express
* **Database**: MongoDB, MySQL
* **Machine Learning**: OpenCV, TensorFlow, YOLOv5
* **Deployment**: Docker, Kubernetes, AWS (EC2, RDS, S3)
* **Security**: OTP, Session Management, Camera Verification
